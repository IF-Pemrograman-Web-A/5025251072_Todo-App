**4. Implement at least one event handler**

***Event Handler yang digunakan di script.js:***

1. checkbox.addEventListener('change', ...) digunakan untuk mengubah status Todo menjadi selesai atau belum selesai saat checkbox dicentang.
2. editBtn.addEventListener('click', ...) digunakan untuk mengedit Todo saat tombol Edit diklik.
3. delBtn.addEventListener('click', ...) digunakan untuk menghapus Todo saat tombol Delete diklik.
4. select.addEventListener('change', ...) digunakan untuk mengubah status Todo melalui pilihan Done, On Progress, atau None.
5. createForm.addEventListener('submit', ...) —digunakan saat form di-submit untuk menambahkan Todo baru atau mengubah Todo yang sudah ada.
6. btn.addEventListener('click', ...) digunakan untuk mengaktifkan atau menonaktifkan Dark Mode saat tombolnya diklik.
